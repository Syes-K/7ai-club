## 3. 功能说明

### F-05 流式聊天

- 发送中禁用重复提交
- 默认助理 + env 解析模型；LLM 仅服务端
- 失败：可读错误；空输入不发送

### F-07 历史列表

- 标题：首条用户消息摘要或「New Chat」
- 按 `updated_at` 降序

### F-09（iter-01 基线）

- 单默认助理，seed 配置；无管理 UI
